Простое настольное приложение на Python (Tkinter) для генерации надёжных паролей.

## Возможности
- Настраиваемая длина пароля
- Выбор категорий символов: строчные, заглавные, цифры, спецсимволы
- Цветовой индикатор силы пароля (красный / жёлтый / зелёный)
- Копирование пароля в буфер обмена одной кнопкой
- Светлая и тёмная тема

## Как запустить
```python password_generator_gui.py ```

## Технологии
Python, Tkinter, модуль `secrets` для криптографически стойкой генерации.
